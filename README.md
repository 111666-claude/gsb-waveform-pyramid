# waveform-pyramid

从游戏录音的 PCM 流生成多分辨率波形金字塔，只用 Python 标准库。

## 口径

- 每一级以固定大小聚合 min、max 和样本数，chunk 边界不能丢失未满桶。
- 高层由低层增量合并，局部追加只影响必要桶；负峰值和单点峰值都必须保留。
- 范围查询的工作量与命中的桶数相关，返回 `work` 作为可观测计数。
- 重建与分块追加得到相同的各级结果。

## 不变量

- 高层每个桶覆盖连续的低层样本。
- min 不大于 max，count 为正。
- level 0 的样本顺序与输入一致。

## 输出契约

CLI 输出 JSON：`levels` 为各级桶列表，桶含 `min`、`max`、`count`；另有 `samples` 与 `work`。
